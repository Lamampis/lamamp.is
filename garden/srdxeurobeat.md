# Guide: Add Eurobeat to Sonic Riders DX

## This is an updated version of Salaga's Eurobeat build, made by me.
Every stage has been updated to have new tracks and many old tracks have been shuffled around. Featuring main menu music from Wangan Midnight! Has a beautiful new banner!

Grab the necessary files [here:](https://drive.google.com/drive/folders/13Nj3NJkSmb4hBU5Ho-cfnzDGZ_5H6VoD)

(I cannot include the whole ISO, that's piracy or whatever)

![Eurobeat](/static/images/garden/srdx_eurobeat.png)

## To Install

- Download all the files in the link above.
- Create a folder named Eurobeat in your Dolphin path folder.
- Right Click on your Sonic Riders DX 2.0.1 iso inside dolphin and select Properties.
- Go the Filesystem tab and right click on Disc and select Extract Entire Disc.
- Extract it on the folder you made previously.
- There should be 2 folders inside the Eurobeat folder, files ans sys.
- Go to the files folder and paste all the files you downloaded in step 1 in there, there should be 104 files that will get replaced.
- Now refresh dolphin and there should be a new entry! But you're not done quite yet.
- Click on the new entry (as indicated by the 0.00 filesize or the new banner) and select "Convert File".
- Just make sure the format is ISO and click Convert.
- Name it whatever you want and place it in your Dolphin Path folder.

### That's it! Your eurobeat dreams have become reality! You can now safely delete the folder you made in step 2.
