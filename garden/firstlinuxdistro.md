# Choosing your first Linux distro should not be hard

I get annoyed when people try to get someone into linux and the first thing they mention is how there's a thousand different distros to choose from.

That's a lie.

**There are only 2 real distros.**
- Arch
- Ubuntu

99% of users will ultimately pick one of these 2 (source: me).

More specifically, there's only 1 distro I'll ever recommend to anyone starting out, and that is Linux Mint (ubuntu based).

Without getting into details, **Linux Mint does everything right.**

**You should use Linux Mint if you want to get into Linux.**

Don't overcomplicate Linux to new users, they don't want/need to hear it.
